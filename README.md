# Spring Boot приложение для управления складом

Мое первое Spring Boot приложение с полным REST API для управления товарами на складе.

## Функциональность

### Основные операции
- **CRUD** - создание, чтение, обновление, удаление товаров
- **Поиск** - по названию, категории, складу
- **Фильтрация** - по цене, количеству
- **Сортировка** - по различным полям

### Бизнес-логика склада
-  **Перемещение товаров** между складами
-  **Приход товара** - увеличение количества
-  **Расход товара** - уменьшение с проверкой остатка
-  **Аналитика** - статистика по категориям, общая стоимость

## Технологии

- **Java 21**
- **Spring Boot 3.5.7**
- **Spring Data JPA**
- **PostgreSQL**
- **Maven**
- **REST API**

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/warehouse` | Все товары |
| GET | `/api/warehouse/{id}` | Товар по ID |
| POST | `/api/warehouse` | Создать товар |
| PUT | `/api/warehouse/{id}` | Обновить товар |
| DELETE | `/api/warehouse/{id}` | Удалить товар |
| PUT | `/api/warehouse/{id}/move` | Переместить между складами |
| PUT | `/api/warehouse/{id}/increase` | Увеличить количество |
| PUT | `/api/warehouse/{id}/decrease` | Уменьшить количество |

## Запуск проекта

1. Клонировать репозиторий:
```bash
git clone https://github.com/Nikro777/Pet-Project-CRUD-App.git
```
2. Настроить базу данных PostgreSQL

3. Запустить приложение:
```bash
mvn spring-boot:run
```
